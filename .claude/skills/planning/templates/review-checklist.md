# {{기능명}} 리뷰 체크리스트

> "이 산출물을 들고 리뷰 미팅에 들어갈 수 있는가?"

## PRD 체크

- [ ] 문제 정의가 한 문장으로 요약 가능한가
- [ ] Non-Goals가 명시되어 있는가
- [ ] 모든 요구사항이 구현/테스트 가능한 수준으로 구체적인가
- [ ] 정책마다 예외 케이스가 하나 이상 고려되었는가
- [ ] 권한별 접근 범위가 정의되었는가 (해당 시)
- [ ] 상태값 전이가 명확한가 (해당 시)
- [ ] UX Flow에 ASCII 다이어그램이 있는가
- [ ] 오픈 이슈가 "의사결정 필요"와 "확인 필요"로 분리되었는가
- [ ] 성공 지표가 측정 방법과 함께 정의되었는가

## 화면명세 체크 (작성한 경우)

- [ ] 모든 화면에 빈 상태(empty state)가 정의되었는가
- [ ] 모든 화면에 에러 상태가 정의되었는가
- [ ] 버튼 라벨이 화면 간 일관적인가
- [ ] 상태 배지 색상/라벨이 화면 간 일관적인가
- [ ] 각 화면에 edge case가 1개 이상 있는가
- [ ] 네비게이션 흐름에 막힌 곳(dead end)이 없는가

## 목업 체크 (작성한 경우)

- [ ] HTML 파일이 브라우저에서 에러 없이 열리는가
- [ ] 모든 버튼이 클릭 가능하고 결과가 보이는가
- [ ] 모달이 열리고 닫히는가
- [ ] 상태 변경이 UI에 반영되는가
- [ ] 샘플 데이터가 현실적인가 (한국어 이름, 실제 날짜)

## 리뷰 준비

- [ ] 리뷰어가 누구인지 정했는가
- [ ] 리뷰에서 결정받아야 할 항목을 오픈 이슈에서 뽑았는가
- [ ] 산출물 파일 경로를 공유할 준비가 되었는가
