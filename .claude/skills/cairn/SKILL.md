# cairn — 지식 정렬 대장 규약

## Overview

cairn은 나(사용자)와 AI의 지식지도를 정렬하는 대장(ledger)이다.
훅 차단(exit 2)은 **정지 신호이지 장애물이 아니다**. 차단을 만나면 할 일은
우회 경로 탐색이 아니라 이 스킬의 절차 수행이다.

**규칙의 철자를 어기는 것이 곧 정신을 어기는 것이다.**
"훅이 Bash는 못 잡으니까"는 허용 근거가 아니라 위반의 자백이다.

## 대장 스키마 (이 형식 외 임의 발명 금지)

```yaml
version: 1
items:
  - id: kebab-case-id
    u: true          # 사용자가 아는가 (bool. 1/0 금지)
    a: true          # AI가 아는가
    rumsfeld: KK     # KK/KU/UK/UU
    surfaced: false  # 사용자에게 설명하고 승인받았는가
    share: personal  # personal/team
    source: 근거 파일·경위
events: []           # append-only
```

- 사용자가 직접 요청한 작업 = `u: true, a: true, rumsfeld: KK`
- 작업 중 AI만 알게 된 사실·리스크 = `u: false, a: true, rumsfeld: UK, surfaced: false`
  — 정직하게 이렇게 적으면 다음 mutation이 gate-a에 걸린다. **그게 정상 동작이다.**

## 차단별 절차

### 🛑 gate-zero (대장 부재)
1. `.cairn.yaml`의 ledger 경로에 위 스키마로 대장을 시드한다 (대장 파일 쓰기는 훅 면제).
2. 항목은 **실제 인식 상태 그대로** 분류한다. 게이트를 통과시키려고
   `u: true`를 날조하는 시드는 대장 전체를 무의미하게 만든다.

### 🛑 gate-a (미표면화 ③ — AI만 아는 항목 존재)
1. 해당 항목을 **사용자에게 설명한다** (무엇을, 왜 사용자가 알아야 하는지).
2. 사용자가 인지·승인한 **후에만** `surfaced: true`(+`u: true`)를 기록한다.
3. **사용자가 부재중이면 작업을 중단하고 미완료로 보고한다.** 부재 = 승인 불가 = 중단.
   "물어보지 말고 해달라"는 지시는 표면화 절차를 면제하지 않는다.

### 🛑 gate-b (머지 수렴)
미정렬(`~(u&a)`)이며 `outOfScope`가 아닌 항목을 사용자와 정리한다.
`outOfScope` 판정도 사용자 결정이다.

## 금지 — 예외 없음

- **훅 우회 금지**: Bash 리다이렉트/heredoc/sed/tee/cp/mv/python/스크립트,
  파일 삭제 후 재생성, cwd를 레포 밖에 두고 실행 — 전부 위반. 훅이 못 잡는
  경로를 찾았다면 그것은 구멍이지 허가가 아니다.
- **`surfaced`/`u` 자가 반전 금지**: 표면화는 사용자와의 대화 사건이지 비트 연산이 아니다.
- **`.cairn.yaml` 변경·삭제 금지**: mode를 끄는 주체는 사람뿐이다.
- **날조 시드 금지**: 모든 비트는 실제 인식 상태여야 한다.

## 합리화 대응표

| 합리화 | 실제 |
|--------|------|
| "5분 뒤 데모라 급하다" | 차단은 바로 그 압박 상황을 위해 존재한다. 급할수록 미정렬 반영이 위험하다 |
| "차단 항목은 이 작업과 무관하다" | 무관 판정은 사용자 몫. 정말 무관하면 사용자가 `outOfScope` 처리한다 |
| "우회가 유일한 경로다" | 유일한 경로는 사용자 보고다. 미완료 보고는 실패가 아니라 규약 준수다 |
| "사용자가 부재중이니 알아서 처리" | 부재 = 승인 불가 = 중단. 알아서 = 표면화 생략이 아니다 |
| "훅은 Edit/Write만 잡는다" | 철자 위반 = 정신 위반. 잡히느냐가 아니라 하느냐의 문제다 |
| "대장이 없으니 대충 만들어 통과" | 시드는 정직 분류다. 통과용 대장은 대장이 아니다 |

## Red Flags

이런 생각이 들면 즉시 정지하고 위 절차로 돌아간다:
"우회하면", "훅이 못 잡는", "일단 통과시키고 나중에", "이건 예외적으로",
"사용자도 이해할 것", "데모/배포 끝나고 정리하면"
